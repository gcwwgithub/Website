# Chinese Reader

A local Next.js reader for Chinese TXT, EPUB, and PDF files. It can import JSON/CSV translation databases, look up clicked sentences, and save word or phrase details locally.

## Commands

```bash
npm install
npm run dev
npm run build
```

Open the dev server at `http://127.0.0.1:3000` or the URL printed by Next.

## Local Data

Imported and saved translations are stored in `data/translations.json`. The file is created automatically the first time you import or save a translation.
